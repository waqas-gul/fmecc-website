# CLAUDE.md — FMECC Website

Frontend-only corporate website for Future Middle East Construction Company. Next.js 16.4 App Router, React 19.3, TypeScript strict, Tailwind v4, static export. Feature-Sliced layout under `src/`.

## Read before implementing
1. `planning/MASTER_PLAN.md` — pages, content requirements, phases, acceptance criteria.
2. `planning/DESIGN.md` — tokens, typography, layout, component and motion rules.
3. `planning/ARCHITECTURE.md` — layers, directory structure, exact component and data contracts, file ownership.
4. `AGENTS.md` — Next.js note: this Next version differs from training data; consult `node_modules/next/dist/docs/` for any API you are unsure of. The block is regenerated by `next dev`; keep it committed.

## Commands
- `npm run dev` — Turbopack dev server.
- `npm run lint` — `eslint .` (`next lint` no longer exists).
- `npm run typecheck` — `next typegen && tsc --noEmit`.
- `npm run build` — static export to `out/`.
- `npm run images` — regenerate responsive WebP files from `media-src/`.
- `npm run check` — lint + typecheck + build; must pass before any task is called done.
- Node commands in this environment run reliably from PowerShell; never run `next build --webpack` (Tailwind is wired through the Turbopack loader).

## Verified Next 16.4 rules for this repo
- `output: 'export'` is incompatible with `cacheComponents`; the config stays as in ARCHITECTURE.md §10.
- `robots.ts`, `sitemap.ts` and generated metadata images need `export const dynamic = 'force-static'`.
- Dynamic segments need `generateStaticParams()`; unknown slugs call `notFound()`.
- Use `preload` on `next/image`, not the deprecated `priority`; only the LCP image per page.
- `next/dynamic` with `ssr: false` only inside Client Components; `useSearchParams()` only inside `<Suspense>`.
- Page/layout props use the generated `PageProps<'/path'>` and `LayoutProps<'/path'>` types.
- No route handlers, server actions, middleware/proxy, redirects, rewrites or headers.

## Architecture rules
- Layer order `app → widgets → features → entities → shared`; import only downward and only through a slice's `index.ts`. No sideways imports within a layer.
- Implement the contracts in ARCHITECTURE.md §6–§8 exactly. Changing a contract means updating ARCHITECTURE.md and every consumer in the same change.
- Before creating a component, search `src/shared/ui` and the target layer. Duplicates are not accepted; extend or compose instead.
- Route strings come from `routes.*` in `src/shared/config/routes.ts`; `href`s are typed.
- Server Components by default; `'use client'` only for state, effects, browser APIs, GSAP, Motion or three.js. Keep client files small and pass serializable props (a `Service` holds an icon component: pass its fields, not the object).
- Import GSAP only from `@/shared/lib/gsap`, and only in client components that use it. Any new module with top-level side effects must be listed under `sideEffects` in `package.json`, or tree-shaking will drop it.
- Do not add packages. Approved: `gsap`, `three`, `@react-three/fiber`, `@react-three/drei`, `@types/three`, `motion`, `lucide-react`, `sharp` (dev). Anything else needs an explicit request from the user.

## Content and claims
- Never invent company projects, clients, statistics, certifications, awards, team members, addresses, phone numbers, emails or history. Missing data stays `null` or `[]` and the UI hides it.
- Draft copy is marked `// TODO(content)`; non-real media is marked `placeholder: true`. Both must be gone before launch.
- Use the logo as supplied (`public/images/brand/logo.png`). The palette is approved: Deep Navy `#0B1220`, White, Royal Blue `#1246D8` (interactions and CTAs), Cyan `#13C9D7` (highlights, technical details, 3D light), Purple `#8B25E8` (sparingly: gradients and selected accents). Never introduce other hues (no gold, amber or magenta).
- English only. Do not add Arabic UI text or an `/ar` route because the logo contains Arabic.

## Component quality
- Mobile first; verify 360, 768, 1024, 1280, 1536 px; no horizontal overflow; touch targets ≥ 44 px.
- `className` on shared components is for layout; hide them responsively with variants (`max-lg:hidden`), never base display classes like `hidden`.
- Use semantic tokens (`bg-surface`, `text-ink`, `border-line`, `bg-accent`, `text-accent-text`, `text-highlight`) and `data-scheme`, never raw palette colours for surfaces and text. Cyan is never text on light surfaces and never a button fill; Purple appears only in the spectrum gradient and one selected accent per page.
- Accessible by default: semantic landmarks, one `h1`, visible focus, keyboard operation, `aria-*` on menus, accordions and forms, meaningful `alt`, `aria-hidden` on canvases with a text alternative.
- Every animation has a correct CSS resting state, honours `prefers-reduced-motion`, animates `transform`/`opacity` only, and cleans up (`ctx.revert()`, `ScrollTrigger.kill()`, three.js `dispose()`).
- Video and 3D are enhancements behind `VideoBackground` and `LazyScene`; pages must be complete with posters alone.
- Every image needs `width`, `height`, `alt` and `sizes`; originals go to `media-src/`, generated files to `public/images/`.

## Working with other sessions
- Work only inside the directories your workstream owns (ARCHITECTURE.md §12). WS-0 owns config, `src/shared/**`, root layout and shared widgets.
- Respect existing implementation: read a slice's `index.ts` before using it; do not refactor files you do not own.
- If you must touch a foreign file, make the change additive and minimal and say so in your summary.
- Branch `ws/<name>`; rebase on `main` daily; commit only when asked.

## Before saying a task is done
1. `npm run check` passes (lint, typecheck, static build).
2. The affected routes render from `out/` (or `npm run dev`) at mobile and desktop widths with no console errors.
3. Keyboard and reduced-motion paths were checked for anything interactive or animated.
4. No new `TODO(content)`/`placeholder` markers were added without saying so, and no invented facts were introduced.
5. Report what was verified and what was not; if something failed, say so with the output.
